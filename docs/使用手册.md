# 桌面系统使用手册（壁纸 + 抽屉 合订本）

这套桌面由两个程序配合工作：

| 名称 | 你看到的东西 | 作用 |
| --- | --- | --- |
| **壁纸**（Lively 里的 Deepseek 图鲸鲸） | 整屏的动态桌面：角色、待办、硬件、天气、DSH 控制台、当前播放、快捷启动、底部时钟 | 显示信息、发指令、启动抽屉 |
| **抽屉**（DesktopPage） | 从屏幕上方滑下来的毛玻璃图标墙 | 放桌面图标、开程序、整理文件 |

两者互相独立，任何一个没起来另一个仍能正常用。

---

## 一、开机与退出

### 开机
登录 Windows 后约 15~20 秒，壁纸和抽屉会自己起来。靠两个计划任务：

| 任务 | 何时跑 | 干什么 |
| --- | --- | --- |
| `DesktopPage Autostart` | 每次登录 | 完整启动：壁纸 → 抽屉 → 硬件/天气采样 → 本地代理 → 看门狗 |
| `DesktopPage Ensure` | 每 2 分钟 | 兜底巡检：谁被杀了就补起来；顺手把「代理没响应时排队的启动」补上 |

想手动拉起来一次（比如重载壁纸）：

```
schtasks /run /tn "DesktopPage Autostart"
```

### 退出
- 抽屉：右键抽屉空白处 → **退出 DesktopPage**（退出时会把系统桌面图标还原）。
  抽屉顶部快捷栏右侧也有「退出程序」。
- 壁纸：右键任务栏托盘的 Lively 图标 → 退出；或在 Lively 里换一张壁纸。

### 重载
- 改了壁纸文件（`index.html` / `*.js` / `*.css`）：重启 Lively 才会生效。
- 改了代理 `dsh-agent.ps1`：只要重启代理，不必动 Lively。

## 二、壁纸：界面分区

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 左边 DEEPSEEK 标识；右上角一个圆形按钮（**左键**启动抽屉、**右键**打开模拟器设置）；旁边小圆点表示抽屉是否在跑 |

| 左下角 | **DOCK / 快捷启动**：6 个格子，点一下开程序 |
| 右侧上 | **DSH / DESKTOP**：DSH 控制台（日志 + 输入框 + 启动/网页/清空 + 余额） |

| 右侧下 | **当前播放 / NOW PLAYING**：歌名、歌手·来源、上一首 / 播放暂停 / 下一首、进度、时间 |
| 底部 | **SYSTEM TIME**：日期时间、今日进度、24 小时刻度条 |
| 中央 | 角色本体；说话气泡；偶尔的「小声说」气泡 |

## 三、壁纸：待办任务

- **添加**：点顶栏输入框（`+ 添加任务…`）→ 输入内容 → 回车。
- **完成 / 取消完成**：点任务前面的方框。
- **删除**：鼠标移到任务上 → 点右侧出现的 `×`。
- 数据存在 `%LOCALAPPDATA%\DesktopPage\todo.txt`，重启后仍在；壁纸换版本也不丢。

## 四、壁纸：DSH 控制台

右侧 `DSH / DESKTOP` 面板，从上到下：

| 元素 | 作用 |
| --- | --- |
| 会话区 | 像网页版一样按对话显示：**你发的指令**（绿色左边框、左侧「你 + 时间」）和 **DSH 的回答**（「DSH + 时间」）。思考过程不显示（它在 `dsh-run.err.log` 里）；上一轮失败时顶部会出现一行 ⚠ 原因 |
| 输入框「给 DSH 发指令…」 | 输入一条指令 → 回车或点「发送」；发出去会立刻出现你的气泡 |
| 启动 | 如果 DSH 没在跑，启动它（不再重复启动，也不会重启正在跑的） |
| 网页 | 用浏览器打开 DSH 网页界面 |
| 清空 | 清空会话（同时清掉日志和上一轮报错，不影响历史文件） |
| ▲ ▼ | 上下翻会话；不足一屏时自动置灰 |
| 余额 | 输入框右侧的 `¥xx.xx`，约 5 分钟刷新一次 |
| 右上小绿点 | 表示 DSH 服务是否在线（绿=就绪/运行中，灰=离线） |

> 发指令后，点会变成「运行中」，跑完自动出现回答；命令是后台 headless 执行的，不会弹窗。
> 会话区只在**你原本停在底部**时自动跟到最新；手动往上翻看历史时不会被新输出弹回底部。

## 五、壁纸：当前播放

面板会显示系统里正在出声的播放器：

| 情况 | 显示 |
| --- | --- |
| 浏览器 / 支持的播放器在播 | 歌名 + 歌手 · 程序名，进度为真实进度 |
| 网易云音乐在播 | 歌名（取窗口标题）+ 歌手 · 网易云音乐，进度前带「≈」表示按播放时长估算 |
| 什么都没放 | 「未在播放 / 打开播放器 / 视频就会显示在这里」 |

三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 上一首 | 切到上一首 |
| ❚❚ / ▶ | 暂停 / 继续 |
| 下一首 | 切到下一首 |

> 三个按钮走系统媒体键，**不会**把播放器窗口弹到前台，也不依赖 Wallpaper Engine。
> 网易云的暂停有 1~2 秒淡出，点完稍等一下即可。

## 八、滚轮与点击：谁先响应

滚轮在**不同位置**有不同行为，这是故意设计的：

| 鼠标位置 | 滚轮行为 |
| --- | --- |
| 右侧 DSH 面板上（桌面前台、没被窗口盖住） | 翻 DSH 会话 |
| 右侧 DSH 面板上、但浏览器/资源管理器盖在它前面 | 照常滚那个窗口（**不会再被面板吞掉**） |
| 模拟器设置面板上 | 翻设置面板内容 |
| 桌面（壁纸空处） | 向下滑 → 拉出抽屉；向上滑 → 收起抽屉 |
| 其它窗口上 | 正常滚动那个窗口 |

> 若出现「在桌面上滚轮拉不出抽屉」，多半是抽屉进程没在跑：点顶栏抽屉按钮，或按 `Ctrl+Alt+Space`。
> 排查 DSH 面板滚轮时先确认**浏览器不是全屏盖在右边**：面板在壁纸层，被盖住时滚的是上层窗口（设计如此，见 `实现手册.md` §13）。

## 九、抽屉：呼出与收起

| 操作 | 效果 |
| --- | --- |
| **光标移到壁纸最下沿停 0.25 秒** | 拉出图标墙（鼠标这一侧的便捷操作；任务栏正上方那条 40px 带，不跟开始菜单抢点击） |
| **抽屉开着时光标移到屏幕最上沿停 0.25 秒** | 收起 |
| `Ctrl + Alt + Space` | 键盘快捷键：任何地方都能拉出 / 收起 |
| `Esc` | 收起 |
| 点面板空白处 | 收起（不会误开程序） |
| 顶栏抽屉按钮（左键） | 启动抽屉程序（若没在跑） |

> 设计上只保留**一个键盘快捷键 + 一个鼠标操作**，不做多余入口。
> 底缘热区触发一次后要先离开边缘 40px 才会再触发，全屏视频/游戏里不会误触；不想要时往 `summon.cmd` 写一行 `edge=0`（恢复 `edge=1`）。

> 抽屉打开时，**光标移到屏幕最上沿停 0.25 秒**也会收起。热区触发一次后要先离开边缘 40px 才会再触发，不会连锁弹。
> 不想要热区：往 `%LOCALAPPDATA%\DesktopPage\summon.cmd` 写一行 `edge=0`（恢复写 `edge=1`）。

打开/收起有约 200ms 的淡入淡出。

## 十、抽屉：图标怎么整理

### 打开
点图标 = 打开（程序、快捷方式、**文件夹**都能开）。顶部「原始桌面」按钮可以临时回到原生桌面。

> 文件夹走的是「本地代理 → 资源管理器新窗口」，实测 30~50ms 就出窗；如果卡住没反应，看 `audit.log` 里那行 `launch dir ... via=agent|run` 就知道断在哪一步。

### 拖动摆放
按住图标拖到空白处松手，图标吸附到最近网格并记住位置（存在 `layout.dat`）。

### 文件夹
| 操作 | 效果 |
| --- | --- |
| 一个图标拖到另一个图标上松手 | 合成一个文件夹（能看到里面 2~4 个迷你图标） |
| 点文件夹 | 弹出小面板，点里面的项目直接打开 |
| 右键文件夹 | 重命名 / 解散文件夹 / 移出成员 |
| 拖文件夹 | 整体移动 |

### 删除与隐藏
| 操作 | 效果 |
| --- | --- |
| 右键图标 → 删除文件到回收站 | 真的删文件（会弹确认框，确认后进回收站） |
| 右键图标 → 从抽屉中移除 | 只从抽屉里藏起来，文件不动（记在 `hidden.dat`） |
| 托盘/右键菜单 → 恢复被移除的图标 | 清空隐藏名单，全部回来 |

### 新增图标
- 桌面新增文件后：托盘或右键菜单 → **重新扫描桌面**。
- 只想加某几个：抽屉顶部「添加应用」或右键菜单 → **添加文件到抽屉…**。

### 悬停
鼠标停在图标上会弹出气泡显示完整文件名（长的也行）；停在文件夹上显示「文件夹名 （N 项）」。

## 十三、常见问题

**壁纸变黑 / 只剩角色**
Lively 里的 WebView 崩了。右键托盘 Lively → 重新加载壁纸，或 `schtasks /run /tn "DesktopPage Autostart"`。

**当前播放一直显示未在播放**
1. 先确认播放器真的在出声（不是暂停）；
2. 网易云需要窗口在后台运行（最小化可以，完全退出不行）；
3. 点一下面板右上小点，看 DSH 是否在线——这个面板的数据来自本地代理，代理没起来就什么都不显示。

**点播放/暂停没反应**
面板的按钮走系统媒体键，等于按了你键盘上的播放键。如果网易云被设成了「关闭媒体键」，就会没反应；可在网易云设置里恢复，或直接用播放器自己的按钮。

**抽屉不出现**
1. 按 `Ctrl+Alt+Space`；
2. 还不行就点壁纸顶栏的抽屉按钮；
3. 快捷键也没反应时，用「文件召唤」绕开键鼠钩子：在 `%LOCALAPPDATA%\DesktopPage\` 新建 `summon.cmd`，里面写一行 `show` 保存 —— 抽屉 0.4 秒内会出来（写 `hide` 是收起）；
4. 仍不行：托盘图标 → 退出，再 `schtasks /run /tn "DesktopPage Autostart"`；看 `wheel.log` 末尾会写明原因。

**删掉图标后桌面图标也不见了**
抽屉退出时会把系统桌面图标还原；如果异常退出没还原，按 `Ctrl+Alt+D`，或右键桌面 → 查看 → 显示桌面图标。

**改动没生效**
壁纸文件（html/js/css）要**重启 Lively**；代理脚本（dsh-agent.ps1）只要**重启代理**。

## 十四、文件都在哪

壁纸（Lively 库）：

```
C:\Users\<你>\AppData\Local\Lively Wallpaper\Library\wallpapers\<壁纸目录>\
```

> 目录名不固定：本机这份是 `dsqq0001.ab1`（Lively 早期分配的 ID），用安装脚本装的话默认叫 `大肥鱼桌面系统`。硬件/天气/待办的数据写哪个目录不用你管 —— 程序会读 Lively 的 `WallpaperLayout.json` 找到「当前正在用的那一份」。

抽屉与代理：

```
C:\Users\<你>\AppData\Local\DesktopPage\
├─ DesktopPage.ahk      抽屉主程序
├─ dsh-agent.ps1        本地代理（给壁纸提供数据与动作）
├─ agent-watch.ps1      代理看门狗
├─ ensure-all.ps1       兜底巡检（每 2 分钟）
├─ AutoHotkey64.exe     运行时
├─ start-all.vbs        开机总启动器
├─ layout.dat           图标位置 / 文件夹
├─ hidden.dat           被移除的图标名单
├─ items.tsv            桌面项目清单
├─ dock.txt             快捷启动 6 格
├─ todo.txt             待办
├─ summon.cmd           调试用「召唤指令」文件（写一行 show / hide / diag / log=200）
├─ dsh-run.log          桌面控制台的会话记录（指令 + 回答；旧文件轮转成 .1）
├─ dsh-run.err.log      执行过程/报错（reasoning 与 dsh 错误；面板只挑错误行显示）
├─ dsh-debug.log        壁纸调试信标（存在 dsh-debug.flag 时才写）
├─ audit.log            统一操作日志（抽屉 + 代理 + 壁纸页面三方共写）
├─ audit-export.txt     审计日志快照（写 log=200 后生成，双击就能看）
├─ icons\               图标缓存
└─ wheel.log            抽屉运行日志
```

代理监听 `http://127.0.0.1:17433`，只在开机/登录后的本机可用。

### 怎么看系统到底做了什么（操作日志）

系统会把**所有操作**写进一份日志 `%LOCALAPPDATA%\DesktopPage\audit.log`，一行一条：

```
2026-11-03 23:39:03.651 [AHK ] open page=1 src=ui
2026-11-03 23:39:04.745 [AHK ] launch.new ok=1 via=agent path="C:\…\计算机辅修" ms=31
2026-11-03 23:39:07.358 [WEB ] media toggle ok=1
```

- `[AHK ]` 抽屉：开合、点图标、建文件夹、隐藏/删除、滚轮与热区
- `[API ]` 本地代理：真正执行的动作（含走了哪条路 `via=` 和耗时 `ms=`）
- `[WEB ]` 壁纸页面：发指令、播放控制、待办增删

**不想敲命令行**：往 `summon.cmd` 写一行 `log=200`，等 1 秒，然后双击同目录的 `audit-export.txt` —— 里面就是最近 200 条。

出问题时按这个顺序看：
1. 有没有「你点的那一下」对应的一行？**没有** = 事件没进系统（输入层/钩子问题）。
2. 有但 `ok=0` / `FAILED`？**有** = 进了但执行失败，看 `via=` 断在哪一步。
3. 都正常但还是慢？看 `dsh-agent.log` 里 `req done … ms` 是否超过 200ms（代理是单线程，慢请求会排队）。

## 十五、重置与卸载

| 想做的事 | 做法 |
| --- | --- |
| 恢复默认图标布局 | 抽屉右键菜单 → 重置图标布局（或删 `layout.dat`） |
