## 1. 三进程 + 三计划任务

```
┌──────────────────────────────── Windows 桌面 ────────────────────────────────┐
│                                                                             │
│  Lively Wallpaper (WebView2, file://)        DesktopPage.ahk (AutoHotkey v2) │
│  wallpapers\<壁纸名>\index.html              抽屉三窗口：                     │
│   ├ app.js   上游模拟器（勿改）               ├ gDrawer  图标层（分层+亚克力）│
│   ├ dsh.js   DSH 控制台 + 快捷启动 + 几何上报  ├ gOverlay 全屏透明事件层       │
│   ├ media.js 当前播放（GSMTC/网易云）          └ gTip     悬停气泡            │
│   ├ todo.js  待办（读 todo-data.js）                                         │
│   ├ hw.js    硬件（读 hw-data.js）                                           │
│   └ wx.js    天气（读 wx-data.js）                                           │
│         │                                            │                       │
│         │ JSONP(<script *.js>) + 1×1 GIF 信标         │ 直接读写文件            │
│         ▼                                            ▼                       │
│   dsh-agent.ps1 ── PowerShell 5.1 HttpListener，单线程，127.0.0.1:17433      │
│         ▲                                                                    │
│         │ 每 1/5 秒巡检：pid + 心跳 + 端口                                    │
│   agent-watch.ps1（看门狗，常驻）      ensure-all.ps1（巡检，每 2 分钟）        │
└─────────────────────────────────────────────────────────────────────────────┘
```

**三条不可违反的事实**（改了必然坏）：

1. **壁纸是 `file://` 页面**，`index.html` 的 CSP 里写着 `connect-src 'none'`，叠加 Chromium 的私有网络限制 —— `fetch`/`XMLHttpRequest` 访问本机端口一律失败。所有通信只有两条老通道：
   - 读数据：动态插 `<script src="http://127.0.0.1:17433/xxx.js?v=时间戳">`，代理返回 `window.__XXX = {...};`
   - 发指令：`new Image().src = '.../xxx.gif?参数'`，代理回一张 1×1 透明 GIF
2. **抽屉是独立进程**，盖在壁纸上层；它不碰页面 DOM，页面也点不到它。两者唯一的实时耦合是**文件**（`panel-rect.txt` / `scroll.dat` / `summon.cmd` / `launch-queue.txt`）。
3. **代理是单线程循环**，`$path` 进 `$script:ROUTES` 路由表（O(1) 查表 → handler）。任何一次超过 ~200ms 的同步操作都会连坐所有接口（历史上 `Start-Process` 拉 `.vbs` 阻塞 6.2 秒，直接把抽屉的鼠标钩子拖死，滚轮失灵半小时）。

4. **唤起抽屉有三条通道**，互不依赖：键鼠钩子（`$WheelDown` / `^!Space`）→ Raw Input（钩子被摘时兜底）→ **屏幕底缘热区**（纯光标位置轮询，任何输入设备都能用，见 §6.5）。三者最后都进 `WheelHandle()` / `ShowDrawer()`。

5. **每天 07:30 有个巡检任务在动这个仓库**（计划任务 大肥鱼 每日巡检 → \tests\Nightly-Check.ps1）：拉 origin/dev 的落后提交 → 跑 \tests\Run-Tests.ps1 → **只要出现高/中危失败就拒绝推送**（退出码 1，别的智能体的重构原样留在本地）；全绿才 git push origin dev:dev，同时把「昨晚改了什么」写成 E:\DSHWORK\nightly\<日期>.md（另有 latest.md）并发系统通知。报告里带 **0–10 分质量点评**（确定性规则打分：没改测试 -3、动高风险文件 -2、没同步文档 -1、通过数比上一轮少 -2、警告变多 -1、单轮 >15 文件或 diff >1500 行各 -1），外加**一段 AI 点评**（只看内联 diff、禁止调工具）。它**永不碰 main** —— main 只由人放行（AGENTS 记忆规则第 9 条）。**巡检结果会以 `[HH:mm:ss] <<< …` 追加进 `DesktopPage\dsh-run.log`**，桌面控制台的会话区把它画成一条带时间的 DSH 气泡（2026-11-06 起），不用开文件夹找报告。推送先走仓库代理，代理连不上时自动用 `git -c http.proxy= -c https.proxy=` 直连重试一次（报告标「（直连）」），rejected/凭据错不重试、照旧报失败（2026-11-06 补丁，CON-016 守着）。

|---|---|---|---|
| `DesktopPage Autostart` | `wscript.exe "<安装目录>\start-all.vbs"` | 登录时 | 完整启动链（壁纸→等 explorer→抽屉→采样→代理→看门狗→dock 宿主） |

## 3. 代理接口全表（`http://127.0.0.1:17433`）

约定：`*.js` 返回 `window.__XXX=…`（`Content-Type: application/javascript`）；`*.gif` 一律返回 1×1 透明 GIF，**且必须「先回包、再干活」**（否则页面 `onload` 要等动作做完，表现为「点了没反应」）。

### 3.1 拉数据（JSONP）

| 路由 | 响应 | 消费者 | 备注 |
|---|---|---|---|
| `/state.js` `/state` | `window.__DSH_STATE={web,scroll,busy,bal,drawer,sig,err,reload,dbg,lines[]}` | `dsh.js` 每 1.2s | `web`=3080 端口探测；`busy`=校验 pid+启动时间；`bal`=DeepSeek 余额（5 分钟缓存）；`drawer`=进程在**且**心跳 `drawer-hb.txt` 新鲜(≤90s)、`items>0`、`pics>=items`（2026-11-14 起：缺图标不再算「运行中」）；`drawerUp`=只看进程在不在（页面据此区分「黄=进程在但图标/心跳异常」与「绿=真可用」）；`sig`=日志身份（`长度-mtime`，页面据此决定要不要拉 `/log.js`）；`err`=上一轮失败原因（stderr 的 `dsh:` 行）；`reload`=热重载令牌；`dbg`=`dsh-debug.flag` 是否存在 |
| `/log.js` | `window.__DSH_LOG="<整段 dsh-run.log>"` | `dsh.js`（`sig` 变了才拉） | 2026-11-05 新增：控制台改成会话气泡，正文走这条；上限 60000 字符（超了截尾并丢掉半行），缓存 400ms |
| `/media.js` | `window.__MEDIA={ok,playing,app,title,artist,pos,dur,est}` | `media.js` 每 1.5s | GSMTC 优先，网易云兜底；`est=1` 表示进度是估算（显示 `≈`） |
| `/dock.js` | `window.__DOCK=[{n,i,p}]` + `window.__DOCK_BUSY` | `dsh.js` 每 1.5s | 读 `dock.txt` + `dock-add.state` |
| `/scroll.js` | `window.__DSH_SCROLL=<±N>` | `dsh.js` 每 40ms | 读 `scroll.dat` 并**清零**（一次性取走）；文件 >1MB 时直接丢弃返回 0（兜底，防异常写入把整份 `ReadAllText` 拖进主循环）；**「读到」不等于「取走」**：删掉 → `Test-Path` 复核 → 删不掉退化成截空再复核 → 都不成就**这一轮返回 0**（意图还在文件里，40ms 后下一轮再取）。旧写法「读完就 `Delete`、删没删掉不管」会让同一批意图**被重复交付**（滚一格跳两格，日志干净），`RES-013` 咬住；**令牌有效时顺带回一句热重载**：**先清令牌、确认清掉了才发**（有 `window.__DSH_RELOAD_OK` 就调它，否则退回 `location.reload()`），发完 `Cache-Drop 'reload'` 免得 `/state.js` 半秒内再下发一次。有效性**只看内容**（`Get-ReloadToken > 0`），空文件/清不掉一律不发 —— 否则 40ms 一轮会无限重插 `dsh.js`（`CON-017` 咬住） |

### 3.3 端口只有一处配置

唯一值在 `drawer\agent-config.ps1` 的 `$AgentPort`（默认 17433）。三个 PowerShell 脚本（`dsh-agent.ps1` / `agent-watch.ps1` / `ensure-all.ps1`）dot-source 它，`-Port` 参数默认 0（= 用配置）；代理启动与 `install.ps1` 把端口落成两份生成物：`%LOCALAPPDATA%\DesktopPage\agent-port.txt`（纯数字，AHK 启动时读）和 Lively 壁纸目录 `port.js`（`window.__DSH_AGENT_PORT=...;`，`index.html` 在 `api.js` 之前加载）；`api.js` 据此拼 `window.__API.url`，其余脚本只读 `__API.url` 或 `__DSH_AGENT_PORT`。

改端口步骤：改 `agent-config.ps1` 一处 → 重跑 `install.ps1`（或只重启代理，让两份生成物刷新）→ 重启抽屉。`CON-001` 咬住「配置源 + 三个 dot-source + 两份生成物 + 读取方」这条链，不再扫九处字面量。

## 4. 文件职责表（改之前先看这一列「注意」）

### 4.1 `drawer\`（抽屉 + 代理，全部是会被 `install.ps1` 拷到 `%LOCALAPPDATA%\DesktopPage` 的文件）

## 6. 排障工具箱

### 6.1 `summon.cmd` —— 不碰键鼠也能指挥抽屉

写一行到 `%LOCALAPPDATA%\DesktopPage\summon.cmd`，抽屉 400ms 内响应并删掉该文件：

| 内容 | 效果 | 日志 |
|---|---|---|
| `show` / `hide` | 打开 / 收起抽屉 | `summon: show via file` |
| `diag` | 落一行现场快照 | `diag: page=… vis=… desk=… cls=… proc=… at=… raw_ok=… raw_alive=… hk_alive=… raw_ticks=… raw_msgs=… wheel_hits=… last_dir=… last_src=… hk_age=… raw_age=…` |
| `foldertest=<文件完整路径>` | 打开它所在的文件夹弹窗 → 调用该成员真正绑定的点击回调 | `foldertest: click tile '…'` → `launch …` |
| `dirtest=<目录完整路径>` | 1.2s 后走真实 `LaunchItem()` 打开该目录（等价于点图标） | `dirtest: begin/fire/done` + `launch dir ok via agent\|run` |
| `classify=<hwnd>` | **直接问判定层**：把这个窗口句柄丢给 `ClassifyDeskWindow()`（2026-11-05 加） | `classify: hwnd=… cls=… proc=… vis=… root=… root_cls=… root_proc=… desk=0/1 page=…` |
| `edge=0` / `edge=1` | 运行时开关底缘热区 | `edge: disabled/enabled` |
| `log=<N>` | 把 `audit.log` 尾部 N 行导出到 `audit-export.txt`（N 默认 200，上限 1000） | `audit.export lines=N` |

排障顺序：先 `diag` 看 `desk`（光标处算不算桌面）→ 真滚一下看 `wheel_hits` 涨不涨 → 涨了看 `last_src`（`hk` 热键 / `raw` Raw Input / `key` 键盘兜底 / `selftest` 自检）→ `wheel_hits` 不涨但 `raw_ticks` 涨 = 钩子掉了。

**`desk` 判错时**不要反复挪光标，直接把可疑窗口的 hwnd 丢进 `classify=<hwnd>`：它会写出该窗口的 `cls/proc/vis`、`GA_ROOT` 顶层窗口的 `root/root_cls/root_proc`，以及 `ClassifyDeskWindow()` 的结论 `desk`。2026-11-05 的「资源管理器里下滑滚轮误召唤」就是用它一次性把 12 个句柄（资源管理器内层 `SHELLDLL_DefView`、`SysTreeView32`、`CabinetWClass`、桌面图标层、壁纸宿主…）的结论全列出来对照定位的，详见 `实现手册.md` §12。

## 7. 改动规则

### 7.1 六条铁律

1. **不要在壁纸里写 `fetch`/`XHR`** —— CSP + 私有网络双杀，只能用 JSONP 与 GIF 信标。
2. **不要改 `app.js`** —— 上游压缩代码，改坏难恢复；要动界面动 `index.html` / `todo.css` / `dsh.js`，且不能删它引用的节点 id。
3. **信标路由先回包再干活**；单线程代理里任何 >200ms 的同步调用都要挪走或缓存。
4. **`.ps1` 存 UTF-8 with BOM**（PS 5.1 无 BOM 会按 GBK 读中文，轻则乱码重则解析失败）；`.vbs` 存 UTF-16LE；`.ahk` UTF-8 无 BOM。
5. **AHK 新函数放文件末尾**，函数内改全局先声明 `global`；数据写入用「tmp + FileMove」。
6. **改完必须验**：`node --check`（改过的 js）→ `Parser::ParseFile`（改过的 ps1，`$err.Count` 必须 0）→ `AutoHotkey64.exe /validate`（改过的 ahk）→ 重启 → `verify.ps1` 退出码 0 → 人眼确认壁纸与抽屉。**临时探针放 `%TEMP%`**，别放 `tests\out` 或仓库内（`STA-002`/`STA-004` 会扫到，假红）。
