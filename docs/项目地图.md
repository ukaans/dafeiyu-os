一句话说明这套东西是什么：**给 Windows 桌面加一层皮**——Lively Wallpaper 里跑的动态壁纸（信息面板 + 角色 + 待办）+ 一个 AutoHotkey 做的全屏图标抽屉，两者通过本机 HTTP 代理 `127.0.0.1:17433` 互通，全部本机运行、不联网（天气是唯一的出网请求）。

## 1. 三进程 + 两计划任务

```
┌──────────────────────────────── Windows 桌面 ────────────────────────────────┐
│                                                                             │
│  Lively Wallpaper (WebView2, file://)        DesktopPage.ahk (AutoHotkey v2) │
│  wallpapers\<壁纸名>\index.html              抽屉三窗口：                     │
│   ├ app.js   上游模拟器（勿改）               ├ gDrawer  图标层（分层+亚克力）│
│   ├ dsh.js   DSH 控制台 + 快捷启动 + 几何上报  ├ gOverlay 全屏透明事件层       │
│   ├ media.js 当前播放（GSMTC/网易云）          └ gTip     悬停气泡            │
│   ├ todo.js  待办（读 todo-data.js）                                         │
│   ├ hw.js    硬件（读 hw-data.js）                                           │
│   └ wx.js    天气（读 wx-data.js）                                           │
│         │                                            │                       │
│         │ JSONP(<script *.js>) + 1×1 GIF 信标         │ 直接读写文件            │
│         ▼                                            ▼                       │
│   dsh-agent.ps1 ── PowerShell 5.1 HttpListener，单线程，127.0.0.1:17433      │
│         ▲                                                                    │
│         │ 每 1/5 秒巡检：pid + 心跳 + 端口                                    │
│   agent-watch.ps1（看门狗，常驻）      ensure-all.ps1（巡检，每 2 分钟）        │
└─────────────────────────────────────────────────────────────────────────────┘
```

**三条不可违反的事实**（改了必然坏）：

1. **壁纸是 `file://` 页面**，`index.html` 的 CSP 里写着 `connect-src 'none'`，叠加 Chromium 的私有网络限制 —— `fetch`/`XMLHttpRequest` 访问本机端口一律失败。所有通信只有两条老通道：
   - 读数据：动态插 `<script src="http://127.0.0.1:17433/xxx.js?v=时间戳">`，代理返回 `window.__XXX = {...};`
   - 发指令：`new Image().src = '.../xxx.gif?参数'`，代理回一张 1×1 透明 GIF
2. **抽屉是独立进程**，盖在壁纸上层；它不碰页面 DOM，页面也点不到它。两者唯一的实时耦合是**文件**（`panel-rect.txt` / `scroll.dat` / `summon.cmd` / `launch-queue.txt`）。
3. **代理是单线程循环**，`$path` 进 `$script:ROUTES` 路由表（O(1) 查表 → handler）。任何一次超过 ~200ms 的同步操作都会连坐所有接口（历史上 `Start-Process` 拉 `.vbs` 阻塞 6.2 秒，直接把抽屉的鼠标钩子拖死，滚轮失灵半小时）。

4. **唤起抽屉有三条通道**，互不依赖：键鼠钩子（`$WheelDown` / `^!Space`）→ Raw Input（钩子被摘时兜底）→ **屏幕底缘热区**（纯光标位置轮询，任何输入设备都能用，见 §6.5）。三者最后都进 `WheelHandle()` / `ShowDrawer()`。

## 2. 进程与自愈（谁拉起谁、谁判定谁）

| 进程 | 由谁拉起 | 存活判定 | 死后谁救 |
|---|---|---|---|
| `Lively.exe` | `start-all.vbs`（`%LIVELY_EXE%` → 常见路径探测） | `tasklist` 有 Lively.exe | 下次登录 / `schtasks /run` |
| `DesktopPage.ahk` | `start-all.vbs` → `AutoHotkey64.exe` | `drawer.pid` 的 pid 确实是 AutoHotkey64；或 `FindWindowW('AutoHotkeyGUI','DesktopPage')` | `ensure-all.ps1`（2 分钟一轮） |
| `dsh-agent.ps1` | `start-all.vbs`；看门狗；巡检 | pid 活着 **且** `dsh-agent.hb` ≤45s **且** 17433 能连上 | `agent-watch.ps1`（5s 一轮，连续 2 次不健康 → taskkill → 重拉，25s 内等它恢复） |
| `agent-watch.ps1` | `start-all.vbs` | `agent-watch.pid` 或互斥体 `Global\DesktopPage_agentwatch` | `ensure-all.ps1` |
| `hwmon.ps1` / `wxmon.ps1` | `start-all.vbs`（各自带互斥体，重复启动自行退出） | 无（写 `*.pid` 仅供参考） | 下次登录 |
| `dock-add-host.ps1` | `start-all.vbs` | 互斥体 `Global\DesktopPage_dockpick` | 下次登录 |

**两个计划任务**（都由 `install.ps1` 建，`uninstall.ps1` 删）：

| 任务名 | 动作 | 触发 | 作用 |
|---|---|---|---|
| `DesktopPage Autostart` | `wscript.exe "<安装目录>\start-all.vbs"` | 登录时 | 完整启动链（壁纸→等 explorer→抽屉→采样→代理→看门狗→dock 宿主） |
| `DesktopPage Ensure` | `wscript.exe "<安装目录>\ensure-all.vbs"` | 每 2 分钟 | 兜底巡检：只补缺失的三件套 + 消费 `launch-queue.txt` |

> **为什么要走计划任务**：直接双击 `Lively.exe` 会丢 WebView2 的 DPI 感知，整屏放大；从 AutoHotkey 进程里拉代理，子进程 `new HttpListener` 会抛「此平台上不支持操作」。

**冷启动实测**：`Start-ScheduledTask '\DesktopPage Autostart'` → 14.3 秒后三件套全部健康，可见控制台窗 0 个。

## 3. 代理接口全表（`http://127.0.0.1:17433`）

约定：`*.js` 返回 `window.__XXX=…`（`Content-Type: application/javascript`）；`*.gif` 一律返回 1×1 透明 GIF，**且必须「先回包、再干活」**（否则页面 `onload` 要等动作做完，表现为「点了没反应」）。

### 3.1 拉数据（JSONP）

| 路由 | 响应 | 消费者 | 备注 |
|---|---|---|---|
| `/state.js` `/state` | `window.__DSH_STATE={web,scroll,busy,bal,drawer,lines[]}` | `dsh.js` 每 1.2s | `web`=3080 端口探测；`busy`=校验 pid+启动时间；`bal`=DeepSeek 余额（5 分钟缓存）；`drawer`=`Get-Process AutoHotkey64` |
| `/media.js` | `window.__MEDIA={ok,playing,app,title,artist,pos,dur,est}` | `media.js` 每 1.5s | GSMTC 优先，网易云兜底；`est=1` 表示进度是估算（显示 `≈`） |
| `/dock.js` | `window.__DOCK=[{n,i,p}]` + `window.__DOCK_BUSY` | `dsh.js` 每 1.5s | 读 `dock.txt` + `dock-add.state` |
| `/scroll.js` | `window.__DSH_SCROLL=<±N>` | `dsh.js` 每 80ms | 读 `scroll.dat` 并**清零**（一次性取走） |

### 3.2 发指令（信标）

| 路由 | 参数 | 动作 | 落盘 |
|---|---|---|---|
| `/run.gif` | `t=指令` | `dsh.cmd headless "<指令>"`，输出重定向到 `dsh-run.log`；**启动前 >256KB 先轮转成 `dsh-run.log.1`** | `dsh-run.pid` = `pid\|启动时间` |
| `/launch.gif` | — | **只在 DSH 完全没监听时** `dsh.cmd quiet`；绝不 restart | — |
| `/open.gif` | — | 浏览器打开 `E:\DSH\.dsh\web-url.txt` 里的地址（默认 `127.0.0.1:3080`） | — |
| `/clear.gif` | — | 清空 `dsh-run.log` | — |
| `/drawer.gif` | — | `schtasks /run /tn "DesktopPage Autostart"` | — |
| `/rect.gif` | `x&y&w&h`（0..10000 万分比） | 壁纸上报控制台矩形；`w>200` 才写 | `panel-rect.txt` |
| `/scroll.gif` | `d=±1` | 追加滚轮意图 | `scroll.dat`（UTF-8-RAW 追加） |
| `/summon.gif` | `d=1\|hide` | 写文件召唤抽屉（**不依赖键鼠钩子**） | `summon.cmd` |
| `/todo.gif` | `op=add\|del\|toggle&t=文本` | 改待办 | `todo.txt` + 壁纸目录 `todo-data.js` |
| `/dock.gif` | `op=del&i=序号` | 删快捷启动项 | `dock.txt` |
| `/adddock.gif` | — | 只写触发文件，由常驻 `dock-add-host.ps1` 毫秒级弹框 | `dock-add.trigger` |
| `/launchpath.gif` | `t=完整路径` | 启动文件：`.lnk` 先 `CreateShortcut` 解析 → 目标存在就直起 exe（绕开 SmartScreen 安全警告）；其余走 `explorer.exe "<路径>"` 中转 | 日志 `dsh-agent.log` |
| `/audit.gif` | `e=事件&k=说明` | 壁纸侧审计信标 → `audit.log` 写一行 `[WEB ] e k`；`e≤32`、`k≤200`，换行/制表/方括号一律剥离 | `audit.log` |
| `/icon/<文件名>.png` | — | 返回抽屉图标缓存（只允许 `[A-Za-z0-9._-]`） | — |
| `/audit.gif` | `e=事件名&k=键值串` | 壁纸页面写审计日志；`e`≤32、`k`≤200，换行/方括号被清洗（防伪造日志行） | `audit.log`（`[WEB ]`） |
| `OPTIONS *` | — | 204 + CORS 头 | — |
| 其它 | — | `{"ok":false}` | — |

> **加接口的成本**：`dsh-agent.ps1` 里 `$script:ROUTES` 加一行 `'/foo.gif' = @{ handler='Invoke-Foo'; kind='foo'; poll=$false; audit=$true }` + 写一个 `Invoke-Foo($ctx,$query)`，**主循环一行都不用改**。前缀路由（如 `/icon/`）放 `$script:ROUTES_PREFIX`。

> `/audit.gif` 是 2026-11-03 新增的：三端（抽屉 `[AHK ]`、代理 `[API ]`、壁纸 `[WEB ]`）写同一份 `audit.log`，用 `grep` 一条时间线就能把「点了没反应」定位到具体一环。

> `/media.gif?op=toggle|back|fwd` 走**系统媒体键**（0xB3 / 0xB1 / 0xB0），不抢前台、不弹窗；对网易云则直接发键。

### 3.3 端口分布在九处

改端口要同时改：`dsh-agent.ps1` 的 `param($Port)`、`agent-watch.ps1` 的 `$Port`、`ensure-all.ps1` 的 `TestPort`、`DesktopPage.ahk` 的 `AGENT_BASE`、`wallpaper\api.js` 的 `BASE`、`dsh.js` / `media.js` / `todo.js` / `audit.js` 各自的回退常量。**没有统一配置项**，`tests\Run-Tests.ps1` 的 `CON-001` 会把九处扫一遍，改漏一处就红。

> 2026-11-03 起壁纸侧的 URL 集中在 `api.js`（`window.__API.url`），其余脚本写成 `(window.__API || {}).url || 'http://127.0.0.1:17433'` 的兜底形态。加新面板请优先用 `window.__API`，别再各写一份常量。

## 6. 排障工具箱

### 6.1 `summon.cmd` —— 不碰键鼠也能指挥抽屉

写一行到 `%LOCALAPPDATA%\DesktopPage\summon.cmd`，抽屉 400ms 内响应并删掉该文件：

| 内容 | 效果 | 日志 |
|---|---|---|
| `show` / `hide` | 打开 / 收起抽屉 | `summon: show via file` |
| `diag` | 落一行现场快照 | `diag: page=… vis=… desk=… cls=… proc=… at=… raw_ok=… raw_alive=… hk_alive=… raw_ticks=… raw_msgs=… wheel_hits=… last_dir=… last_src=… hk_age=… raw_age=…` |
| `foldertest=<文件完整路径>` | 打开它所在的文件夹弹窗 → 调用该成员真正绑定的点击回调 | `foldertest: click tile '…'` → `launch …` |
| `dirtest=<目录完整路径>` | 1.2s 后走真实 `LaunchItem()` 打开该目录（等价于点图标） | `dirtest: begin/fire/done` + `launch dir ok via agent\|run` |
| `edge=0` / `edge=1` | 运行时开关底缘热区 | `edge: disabled/enabled` |
| `log=<N>` | 把 `audit.log` 尾部 N 行导出到 `audit-export.txt`（N 默认 200，上限 1000） | `audit.export lines=N` |

排障顺序：先 `diag` 看 `desk`（光标处算不算桌面）→ 真滚一下看 `wheel_hits` 涨不涨 → 涨了看 `last_src`（`hk` 热键 / `raw` Raw Input / `key` 键盘兜底 / `selftest` 自检）→ `wheel_hits` 不涨但 `raw_ticks` 涨 = 钩子掉了。

### 6.2 抽屉自检启动参数（`AutoHotkey64.exe DesktopPage.ahk <参数>`）

| 参数 | 用途 |
|---|---|
| `--selftest` | 无人值守跑「移除→恢复、建夹→改名→解散」，**结束后把 `layout.bak`/`hidden.bak` 盖回去** |
| `--launch=<路径>` | 1.2s 后走真实 `LaunchItem()` 打开该路径 |
| `--wheel=1\|-1\|seq` | 直接调滚轮决策层 `WheelHandle()`，绕开输入通道 |
| `--page=N` / `--show` / `--plain` | 打开到第 N 页 / 直接展开 / 关亚克力 |
| `--rescan` / `--todo-sync` / `--restore` | 重扫桌面 / 同步待办到 `todo-data.js` / 清空隐藏名单 |
| `--diag` / `--scrolltest` / `--tiptest` / `--rename=` | 单点诊断 |

所有一次性入口都必须 `ONESHOT := true`，否则退出时 `ExitCleanup` 会把系统桌面图标放出来。

### 6.5 审计日志怎么读（新增）

`%LOCALAPPDATA%\DesktopPage\audit.log`，一行一条，三方共写：

```
2026-11-03 23:39:02.274 [AHK ] summon cmd=show
2026-11-03 23:39:03.651 [AHK ] open page=1 src=ui
2026-11-03 23:39:04.745 [AHK ] launch.new ok=1 via=agent path="C:\…\计算机辅修" ms=31
2026-11-03 23:39:04.782 [API ] launch path="C:\…\计算机辅修" via=dir ok=1 ms=45
2026-11-03 23:39:07.358 [WEB ] media toggle ok=1
```

- `[AHK ]` 抽屉：开合、启动（含走的哪条路与耗时）、建夹/解散、隐藏/删除、滚轮与热区动作、待办同步。
- `[API ]` 代理：**动作型**请求一行（含耗时、`route=` 分类）+ 业务结果（如 `via=lnk-exe|dir|explorer`）。
- `[WEB ]` 壁纸页面：发指令、四个按钮、播放控制、待办增删勾、控制台转离线。

**用户自己怎么看**：不用命令行 —— 写一行 `log=200` 到 `summon.cmd`，然后双击同目录的 `audit-export.txt`。

**排障三板斧**：①先看有没有「你点的那一下」的那行（没有 = 事件没进系统）；②再看 `ok=0` / `FAILED`（有 = 进了但执行失败，`via=` 指出断在哪）；③最后对照 `dsh-agent.log` 的 `req done` 耗时（>200ms 说明单线程被拖住）。

### 6.6 底缘热区（新增的第三条唤起通道）

- **抽屉关着**：光标移到**壁纸最下沿那条（任务栏正上方约 40px 的带子）**停 0.25 秒 → 抽屉滑出。
- **抽屉开着**：光标移到**屏幕最上沿**停 0.25 秒 → 收起。
- 触发一次后要先离开边缘 40px 以上才会重新生效（防连锁弹）。
- 热区只认「桌面/壁纸」窗口，全屏视频/游戏里不会误触；任务栏本身被排除，不与开始菜单/托盘抢点击。
- 关了想开：`summon.cmd` 写 `edge=1`；不想要：写 `edge=0`。生效参数看 `wheel.log` 的 `edge: probe init … zone=1320..1360`（本机 2560×1440、任务栏 72px）。

## 7. 改动规则

### 7.1 六条铁律

1. **不要在壁纸里写 `fetch`/`XHR`** —— CSP + 私有网络双杀，只能用 JSONP 与 GIF 信标。
2. **不要改 `app.js`** —— 上游压缩代码，改坏难恢复；要动界面动 `index.html` / `todo.css` / `dsh.js`，且不能删它引用的节点 id。
3. **信标路由先回包再干活**；单线程代理里任何 >200ms 的同步调用都要挪走或缓存。
4. **`.ps1` 存 UTF-8 with BOM**（PS 5.1 无 BOM 会按 GBK 读中文，轻则乱码重则解析失败）；`.vbs` 存 UTF-16LE；`.ahk` UTF-8 无 BOM。
5. **AHK 新函数放文件末尾**，函数内改全局先声明 `global`；数据写入用「tmp + FileMove」。
6. **改完必须验**：`node --check`（改过的 js）→ `Parser::ParseFile`（改过的 ps1，`$err.Count` 必须 0）→ `AutoHotkey64.exe /validate`（改过的 ahk）→ 重启 → `verify.ps1` 退出码 0 → 人眼确认壁纸与抽屉。
